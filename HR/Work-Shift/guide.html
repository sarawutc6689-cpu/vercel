คู่มือการใช้งาน

หน้าหลัก ตารางกะ อนุมัติตารางกะ ปฏิทินวันหยุด รายงาน แดชบอร์ด บัญชีธุรการ บัญชีผู้จัดการแผนก คู่มือ

คู่มือการใช้งานระบบตารางกะการทำงาน

เลือกบทบาทของคุณเพื่อดูเฉพาะหัวข้อที่เกี่ยวข้อง หรือเลือก "ทั้งหมด" เพื่ออ่านทุกหัวข้อ

ภาพรวมและสิทธิ์การใช้งาน

ระบบนี้ใช้บันทึก ตรวจสอบ และอนุมัติตารางกะการทำงานของพนักงานที่ปฏิบัติงานที่ โรงงาน เป็นรายแผนก รายสัปดาห์ (จันทร์–อาทิตย์) โดยแบ่งผู้ใช้เป็น 3 บทบาท

บทบาททำอะไรได้
ธุรการลงตารางกะของแผนกที่ตนรับผิดชอบ ส่งตารางกะขออนุมัติ ดูรายงาน แดชบอร์ด และปฏิทินวันหยุด (ดูอย่างเดียว) ส่งออกรายงานเป็น PDF ได้
ผู้จัดการแผนกตรวจและ อนุมัติ หรือ ส่งกลับแก้ไข ตารางกะของแผนกที่ตนอนุมัติ ดูรายงานและแดชบอร์ด ส่งออก Excel / CSV / PDF ได้
ฝ่ายบุคคลเห็นทุกแผนก กำหนดวันหยุดในปฏิทิน สร้างและจัดการบัญชีธุรการและผู้จัดการแผนก อนุมัติแทนได้ และเป็นผู้เดียวที่ ยกเลิกการอนุมัติ ได้
หน้าธุรการผู้จัดการแผนกฝ่ายบุคคล
ตารางกะ (ลงกะ)✓–✓

ปฏิทินวันหยุดดูอย่างเดียวดูอย่างเดียวแก้ไขได้

จัดการบัญชีธุรการ / ผู้จัดการแผนก––✓
แต่ละคนเห็นข้อมูลเฉพาะแผนกที่ตนมีสิทธิ์ ถ้าไม่เห็นแผนกที่ควรเห็น ให้แจ้งฝ่ายบุคคลเพื่อตรวจสอบการกำหนดแผนกของบัญชี

ขั้นตอนการทำงานแต่ละสัปดาห์

ฝ่ายบุคคลตั้งวันหยุดกำหนดวันหยุดบริษัทและวันหยุดพิเศษ 75% ในปฏิทิน (วันอาทิตย์ระบบถือเป็นวันหยุดอยู่แล้ว)
ธุรการลงตารางกะเลือกกะ ช่วงวันที่ แล้วบันทึก ทำจนครบทุกคนทุกวันของสัปดาห์
ธุรการส่งขออนุมัติตรวจฟอร์มในหน้า "อนุมัติตารางกะ" แล้วกดส่ง ตารางกะสัปดาห์นั้นจะถูกล็อก
แจ้งเตือนทาง Telegramระบบส่งข้อความเข้ากลุ่มพร้อมปุ่มเปิดหน้าอนุมัติ
ผู้จัดการตรวจและตัดสินอนุมัติ หรือส่งกลับพร้อมเหตุผล
จบงาน หรือแก้ไขแล้วส่งใหม่อนุมัติแล้วตารางถูกล็อกและพิมพ์ PDF ได้ ถ้าถูกส่งกลับ ธุรการแก้ไขแล้วส่งใหม่

เข้าสู่ระบบและเมนู

  1. เปิดหน้าที่ต้องการ (เช่น หน้าหลัก) กรอก อีเมล และ รหัสผ่าน ที่ฝ่ายบุคคลให้ แล้วกด เข้าสู่ระบบ
  2. มุมขวาบนแสดงชื่อ-นามสกุลของคุณ (เอาเมาส์ชี้เพื่อดูอีเมล) กด ออกจากระบบ เมื่อใช้เสร็จ โดยเฉพาะเครื่องที่ใช้ร่วมกัน
  3. แถบเมนูด้านบนใช้สลับระหว่างหน้า เมนูบัญชีธุรการและบัญชีผู้จัดการแผนกแสดงเฉพาะฝ่ายบุคคล
  4. ลืมรหัสผ่าน ให้แจ้งฝ่ายบุคคลเพื่อรีเซ็ตให้

ลงตารางกะ ธุรการ

หน้า ตารางกะ ใช้บันทึกกะของพนักงานทั้งแผนกเป็นช่วงวันที่ในครั้งเดียว

  1. กลุ่มพนักงาน เลือก "พนักงาน" หรือ "หัวหน้างาน" ตำแหน่งที่มีคำว่า "หัวหน้างาน" จะอยู่กลุ่มหัวหน้างาน ที่เหลืออยู่กลุ่มพนักงาน แต่ละกลุ่มมีรหัสกะของตัวเอง
  2. แผนก เลือกแผนกที่คุณรับผิดชอบ (เห็นเฉพาะแผนกของตน)
  3. รหัสกะ เลือกรหัสกะที่ต้องการจากรายการ
  4. วันที่เริ่ม และ ถึงวันที่ เลือกช่วงวันที่ที่จะใช้กะนี้
  5. เลือกพนักงานที่ต้องการในรายชื่อ แล้วกด บันทึกตารางกะ
  6. ดูผลได้ในส่วน ตารางกะที่บันทึกไว้ ด้านล่าง กด รีเฟรช เพื่อโหลดข้อมูลล่าสุด
วันหยุดไม่ต้องเลือกเอง ระบบแสดงวันอาทิตย์ วันหยุดบริษัท และวันหยุดพิเศษ 75% ตามปฏิทินให้อัตโนมัติ รวมรหัส OFF ของกะนั้นตามประเภทการจ้าง (รายเดือน / รายวัน) ช่องวันหยุดที่ยังไม่ได้ลงกะจะแสดงคำว่า "หยุด"
แสดงเฉพาะพนักงานที่สถานที่ปฏิบัติงานเป็น "โรงงาน" หากไม่พบชื่อพนักงานที่ควรมี ให้ตรวจข้อมูลสถานที่ปฏิบัติงานและสถานะการทำงานของพนักงานคนนั้น
เมื่อส่งขออนุมัติหรืออนุมัติแล้ว สัปดาห์นั้นจะถูกล็อก บันทึกหรือแก้ไขไม่ได้ จะแก้ได้อีกเมื่อผู้อนุมัติส่งกลับ หรือฝ่ายบุคคลยกเลิกการอนุมัติ

ส่งขออนุมัติ ธุรการ

  1. เปิดหน้า อนุมัติตารางกะ กดช่อง แผนก แล้วติ๊กเลือกแผนก (เลือกได้หลายแผนก มีช่องค้นหา) จากนั้นเลือก สัปดาห์ ด้วยปุ่มลูกศรหรือช่องวันที่ (ระบบปัดเป็นวันจันทร์ถึงอาทิตย์ให้)
  2. ตรวจฟอร์มที่แสดง ช่องที่มีกรอบสีแดง คือช่องที่ยังไม่ได้ลงกะ กลับไปลงในหน้า "ตารางกะ" ให้ครบก่อน แล้วรีเฟรชหน้านี้
  3. กด ส่งขออนุมัติ ยืนยันในหน้าต่างที่ขึ้นมา (ถ้าเลือกหลายแผนก ปุ่มจะบอกจำนวน เช่น "ส่งขออนุมัติ (3 แผนก)" และส่งทีเดียวทุกแผนก)
  4. สถานะเปลี่ยนเป็น รออนุมัติ และผู้จัดการจะได้รับแจ้งเตือนทาง Telegram

ถ้าถูกส่งกลับแก้ไข

สถานะจะเป็น ส่งกลับแก้ไข พร้อมเหตุผลในแถบสถานะ และขึ้นในกล่อง "งานที่ต้องดำเนินการ" ด้านบนของหน้า แก้ตารางกะในหน้า "ตารางกะ" ตามเหตุผล แล้วกดส่งขออนุมัติใหม่

สถานะที่พบ

สถานะความหมายแก้ตารางกะได้หรือไม่
ยังไม่ส่งขออนุมัติยังอยู่ระหว่างลงกะได้
รออนุมัติส่งแล้ว รอผู้จัดการตัดสินไม่ได้ (ล็อก)
อนุมัติแล้วผู้จัดการอนุมัติเรียบร้อยไม่ได้ (ล็อก)
ส่งกลับแก้ไขผู้จัดการให้แก้ไข ดูเหตุผลในแถบสถานะได้

อนุมัติหรือส่งกลับ ผู้จัดการแผนก ฝ่ายบุคคล

  1. เปิดหน้า อนุมัติตารางกะ จากปุ่ม "เปิดหน้าอนุมัติ" ในข้อความ Telegram หรือจากกล่อง งานที่ต้องดำเนินการ ด้านบนของหน้า (กดที่รายการเพื่อเปิดแผนกและสัปดาห์นั้น)
  2. ตรวจฟอร์มตารางกะของแผนก ดูผู้ส่งและเวลาส่งได้ในแถบสถานะ และดูประวัติการดำเนินการที่ด้านล่างของหน้า
  3. กด อนุมัติ เพื่ออนุมัติ หรือกด ส่งกลับแก้ไข แล้ว ระบุเหตุผล (บังคับ) เพื่อให้ธุรการรู้ว่าต้องแก้ไขอะไร
ตรวจหลายแผนกพร้อมกัน ติ๊กเลือกหลายแผนกได้ ฟอร์มของแต่ละแผนกแสดงต่อกัน ปุ่มอนุมัติและส่งกลับจะทำกับทุกแผนกที่อยู่ในสถานะรออนุมัติ และแจ้งผลรายแผนก หากบางแผนกไม่สำเร็จ แผนกที่เหลือยังสำเร็จตามปกติ

ยกเลิกการอนุมัติ เฉพาะฝ่ายบุคคล

ถ้าอนุมัติไปแล้วแต่ต้องแก้ไข ฝ่ายบุคคลกด ยกเลิกการอนุมัติ พร้อมเหตุผล ตารางกะจะปลดล็อกให้ธุรการแก้ไขและส่งขออนุมัติใหม่

ส่งออก PDF

กด ส่งออก PDF ในหน้าต่างพิมพ์เลือก "บันทึกเป็น PDF" ได้ฟอร์มขนาด A4 แนวตั้ง แผนกละ 1 หน้า เลือกหลายแผนกจะได้หลายหน้าในไฟล์เดียว

วิธีอ่านฟอร์มตารางกะ

ฟอร์มในหน้าอนุมัติตามแบบ "ตารางกะแผนก…" ของบริษัท ประกอบด้วย

  • ตารางรายวัน ลำดับ รหัสพนักงาน ชื่อ ตำแหน่ง และ 7 วัน (จันทร์–อาทิตย์) ของสัปดาห์ที่เลือก ช่องวันทำงานแสดงรหัสกะ ช่องวันหยุดแสดงรหัส OFF
  • รหัส OFF พนักงานรายเดือนแสดงเช่น OFF-A000_M พนักงานรายวันแสดงเช่น OFF-A000_D ถ้าขึ้นแค่ "OFF" แปลว่าระบบยังไม่ทราบประเภทการจ้างหรือรหัสของกะนั้น ให้แจ้งฝ่ายบุคคล
  • Dashboard Summary ตารางสรุปจำนวนคนต่อกะพร้อมเวลาทำงาน และกราฟแท่ง นับจากกะที่แต่ละคนใช้บ่อยที่สุดในสัปดาห์นั้น
  • ช่องลงชื่อ ผู้จัดทำ (ธุรการ) แสดงชื่อผู้ส่งและเวลาส่ง ผู้อนุมัติ (ผู้จัดการแผนก) แสดงชื่อและเวลาเมื่ออนุมัติแล้ว
  • คอลัมน์ หมายเหตุ / งานที่ได้รับ เว้นว่างไว้สำหรับเขียนด้วยมือหลังพิมพ์

ปฏิทินวันหยุด

แสดงวันหยุดของทั้งปีเป็นปฏิทิน ใช้เป็นฐานให้หน้าตารางกะและหน้าอนุมัติแสดงวันหยุดและรหัส OFF ให้ตรงกัน

ประเภทสีที่มา
วันหยุดปกติ (วันอาทิตย์)แดงจางระบบกำหนดให้อัตโนมัติ
วันหยุดบริษัทเหลืองจางฝ่ายบุคคลกำหนด
วันหยุดพิเศษ 75%เขียวจางฝ่ายบุคคลกำหนด

ใช้ปุ่ม วันนี้ เพื่อกลับมาเดือนปัจจุบัน ธุรการและผู้จัดการแผนกดูได้อย่างเดียว

เพิ่มวันหยุด ฝ่ายบุคคล

  1. กด + เพิ่มวันหยุด
  2. เลือกวันที่ ประเภท (วันหยุดบริษัท หรือ วันหยุดพิเศษ 75%) และตั้งชื่อวันหยุด แล้วบันทึก
  3. แก้ไขหรือลบได้จากรายการวันหยุดที่กำหนดไว้ใต้ปฏิทิน
วันหยุดที่เพิ่มหรือเปลี่ยน มีผลกับการแสดงผลของทุกสัปดาห์ที่เกี่ยวข้องทันที ควรทำก่อนที่ธุรการจะเริ่มลงกะของสัปดาห์นั้น

รายงาน

มี 2 แท็บ

  • ตารางกะรายเดือน เมทริกซ์พนักงาน × วันที่ ตามช่วงวันที่ที่เลือก
  • ยังไม่ลงกะ รายชื่อพนักงานที่ยังไม่ได้ลงกะ แยกเป็น "ยังไม่ลงเลย" และ "ลงบางส่วน"

กรองด้วย ตั้งแต่วันที่ – ถึงวันที่ แผนก กลุ่มพนักงาน (พนักงาน / หัวหน้างาน) สถานะ และช่องค้นหา รายงานแสดงเฉพาะพนักงานที่สถานที่ปฏิบัติงานเป็น "โรงงาน"

ส่งออกไฟล์

ปุ่มได้อะไรใครใช้ได้
ส่งออก Excelไฟล์ .xlsx คอลัมน์ A = รหัสพนักงาน คอลัมน์ B เป็นต้นไป = วันที่ผู้จัดการแผนก, ฝ่ายบุคคล
ส่งออก CSVไฟล์ .csv รูปแบบเดียวกับ Excelผู้จัดการแผนก, ฝ่ายบุคคล
ส่งออก PDFพิมพ์ตารางที่แสดงอยู่เป็น PDF (A4 แนวนอน) เลือก "บันทึกเป็น PDF" ในหน้าต่างพิมพ์ทุกบทบาท
ธุรการจะไม่เห็นปุ่ม Excel และ CSV เห็นเฉพาะ PDF

แดชบอร์ด

  • ภาพรวมพนักงาน จำนวนพนักงานที่กำลังทำงาน แยกตามฝ่าย สถานที่ และประเภทการจ้าง
  • ภาพรวมการลงกะ ความคืบหน้าการลงกะรายแผนกในเดือนที่เลือก เรียงจากน้อยไปมาก เพื่อเห็นแผนกที่ยังลงไม่ครบ

เลือกเดือน แผนก และกลุ่มพนักงานได้จากตัวกรองด้านบน

การนับเป็นรายวัน ต้องมีข้อมูลครบทุกวันของเดือน (รวมวันอาทิตย์และวันหยุด) จึงนับว่า "ลงครบ"

จัดการบัญชีผู้ใช้ ฝ่ายบุคคล

มี 2 หน้า คือ บัญชีธุรการ และ บัญชีผู้จัดการแผนก ใช้งานเหมือนกัน

สร้างบัญชี

  1. กด + เพิ่มบัญชี
  2. กรอก ชื่อ-นามสกุล อีเมล (ใช้เข้าระบบ) และ รหัสผ่าน อย่างน้อย 8 ตัวอักษร (กด "สุ่มรหัสผ่าน" ได้)
  3. เลือก แผนก ที่รับผิดชอบหรืออนุมัติ ติ๊กทีละแผนก หรือกด "เลือก/ยกเลิกทั้งฝ่าย" เลือกได้หลายแผนก
  4. กดสร้างบัญชี ระบบจะแสดงรหัสผ่านให้ คัดลอกเก็บ เพียงครั้งเดียว ส่งให้เจ้าของบัญชีโดยตรง

จัดการบัญชีที่มีอยู่

  • แก้ไข เปลี่ยนชื่อหรือแผนก
  • รีเซ็ตรหัสผ่าน ตั้งรหัสใหม่ให้ผู้ที่ลืมรหัสผ่าน
  • ระงับ / เปิดใช้งาน ปิดหรือเปิดการเข้าระบบชั่วคราว
  • ลบ ลบบัญชีถาวร
  • ตัวนับ "ยังไม่มีธุรการ/ผู้อนุมัติ N แผนก" ช่วยเช็กว่ายังมีแผนกที่ไม่มีคนดูแล
อีเมลนี้มีบัญชีอยู่แล้ว หากอีเมลถูกใช้ในระบบอื่นของบริษัทอยู่แล้ว ระบบจะถามว่าจะใช้บัญชีเดิมเป็นผู้อนุมัติหรือไม่ ถ้าตกลง จะผูกสิทธิ์ให้โดยไม่เปลี่ยนรหัสผ่านเดิม บัญชีแบบนี้มีป้าย "บัญชีร่วม" และรีเซ็ตรหัสผ่าน ระงับ หรือลบไม่ได้จากหน้านี้ (ทำได้เฉพาะ "เอาออกจากผู้อนุมัติ")
Telegram chat ID (ไม่บังคับ) ข้อความแจ้งเตือนส่งเข้ากลุ่มอยู่แล้ว ปล่อยช่องนี้ว่างได้ กรอกเฉพาะเมื่อต้องการให้ผู้จัดการคนนั้นได้ข้อความส่วนตัวเพิ่ม (ต้องกด Start กับบอทก่อน) กด "ทดสอบ Telegram" เพื่อเช็กว่าข้อความไปถึง

คำถามที่พบบ่อย

บันทึกตารางกะไม่ได้ ขึ้นว่า "ตารางกะสัปดาห์นี้ถูกล็อก"

สัปดาห์นั้นอยู่ในสถานะ "รออนุมัติ" หรือ "อนุมัติแล้ว" ต้องให้ผู้อนุมัติกด "ส่งกลับแก้ไข" (หรือฝ่ายบุคคลกด "ยกเลิกการอนุมัติ") จึงจะแก้ได้

ไม่เห็นชื่อพนักงานหรือแผนกที่ควรเห็น

ระบบแสดงเฉพาะพนักงานที่สถานที่ปฏิบัติงานเป็น "โรงงาน" และเฉพาะแผนกที่บัญชีของคุณมีสิทธิ์ ให้แจ้งฝ่ายบุคคลตรวจข้อมูลพนักงานและการกำหนดแผนกของบัญชี

ช่องวันหยุดในฟอร์มขึ้นแค่ "OFF"

ระบบหารหัส OFF ไม่ได้ เพราะพนักงานยังไม่ระบุประเภทการจ้าง (รายเดือน / รายวัน) หรือกะนั้นยังไม่มีรหัส OFF ในระบบ แจ้งฝ่ายบุคคลให้ตรวจข้อมูล

ขึ้นข้อความ "ตรวจสิทธิ์ไม่สำเร็จ" หรือ "Invalid API key"

เป็นปัญหาการตั้งค่าระบบ ไม่ใช่รหัสผ่านของคุณ ให้แจ้งฝ่ายบุคคลหรือผู้ดูแลระบบ

ธุรการไม่เห็นปุ่มส่งออก Excel / CSV

เป็นการจำกัดสิทธิ์โดยตั้งใจ ธุรการส่งออกได้เฉพาะ PDF หากต้องการไฟล์ Excel หรือ CSV ให้ขอจากผู้จัดการแผนกหรือฝ่ายบุคคล

ส่งขออนุมัติแล้ว แต่ผู้จัดการไม่ได้รับข้อความ Telegram

ข้อความส่งเข้ากลุ่มที่ตั้งไว้ ให้เช็กว่าผู้จัดการอยู่ในกลุ่ม หรือเปิดหน้า "อนุมัติตารางกะ" โดยตรง ที่กล่อง "งานที่ต้องดำเนินการ" จะเห็นรายการที่รออนุมัติเสมอ ถ้าไม่มีข้อความเข้ากลุ่มเลย แจ้งฝ่ายบุคคลให้ตรวจการตั้งค่าแจ้งเตือน

อนุมัติผิดแผนก หรืออนุมัติแล้วพบว่าต้องแก้

แจ้งฝ่ายบุคคลให้กด "ยกเลิกการอนุมัติ" พร้อมเหตุผล ตารางกะจะปลดล็อกให้ธุรการแก้ไขและส่งขออนุมัติใหม่ ทุกการดำเนินการมีบันทึกในประวัติของสัปดาห์นั้น
