FOM-008-IT Rev.01 (26/04/2022)

โครงสร้างการทำงาน: Supabase + GitHub + Vercel

ไฟล์ HTML นี้ถูกออกแบบให้สามารถนำไปวางใน GitHub Repository และเชื่อมต่อกับ Vercel เพื่อเปิดใช้งานเป็นเว็บแอปพลิเคชันได้ทันที โดยดึงข้อมูลจากตารางใน schema public ของคุณ (เช่น assets, employees, asset_departments, buildings, floors, pm_record_pm)

  1. ขั้นตอนที่ 1 (Supabase): ไปที่เมนู Project Settings → API ใน Supabase เพื่อคัดลอก Project URL และ anon public key จากนั้นตรวจสอบให้แน่ใจว่าตาราง assets เปิดสิทธิ์การอ่านข้อมูล (SELECT Policy) เรียบร้อยแล้ว
  2. ขั้นตอนที่ 2 (GitHub): สร้าง Repository ใหม่บน GitHub และอัปโหลดไฟล์ index.html นี้ขึ้นไปไว้ที่ Root ของโปรเจกต์
  3. ขั้นตอนที่ 3 (Vercel): ล็อกอินเข้า Vercel กด Add New... → Project เลือก GitHub Repository ที่เพิ่งสร้าง แล้วกด Deploy (เนื่องจากเป็น Static HTML จึงไม่ต้องตั้งค่า Build Command ใดๆ)

การจับคู่คอลัมน์จากตาราง public.assets อัตโนมัติ

ระบบรองรับชื่อคอลัมน์มาตรฐานหลากหลายรูปแบบในตาราง assets ของคุณโดยอัตโนมัติ หรือคุณสามารถสร้าง SQL View เพื่อรวมตารางเข้าด้วยกันได้ดังนี้:

-- ตัวอย่างการสร้าง View ใน Supabase SQL Editor เพื่อเชื่อมข้อมูลสถานที่ตั้งและชื่อผู้รับผิดชอบ
CREATE OR REPLACE VIEW public.v_it008_assets AS
SELECT
  a.id,
  a.computer_name,
  a.ip_address,
  a.cpu,
  a.ram,
  a.hdd,
  a.vga,
  a.mainboard,
  a.monitor,
  a.keyboard,
  a.mouse,
  a.wireless_adapter,
  a.others,
  CONCAT_WS(' / ', b.name, f.name, d.name) AS location,
  e.full_name AS responsible_person
FROM public.assets a
LEFT JOIN public.buildings b ON a.building_id = b.id
LEFT JOIN public.floors f ON a.floor_id = f.id
LEFT JOIN public.asset_departments d ON a.department_id = d.id
LEFT JOIN public.employees e ON a.employee_id = e.id;
