🔗 ผูกบัญชี Telegram

กรอกรหัสพนักงานและ Chat ID เพื่อรับการแจ้งเตือน

วิธีหา Chat ID:

  1. ค้นหาบอทของบริษัทใน Telegram แล้วกด Start
  2. พิมพ์ข้อความอะไรก็ได้ส่งไปหาบอท 1 ครั้ง
  3. ระบบจะดึง Chat ID ของคุณอัตโนมัติ (หรือติดต่อแอดมินเพื่อขอรับ ID)

พบข้อมูลพนักงาน:

หากเคยผูกไว้แล้ว ระบบจะดึงข้อมูลเดิมมาให้
